# RSKA Notes v17

Complete GitHub Pages/PWA testing build.

## Main workflow
- First screen: Setup or Collection.
- Setup records project/MP details, calibration level, calibrator model/serial, optional calibration photo, weather, observed sources, weather station, optional installation photos, notes and leaving-site time. Duration is not requested.
- Setup PDF contains an embedded structured RSKA data marker for later collection import.
- Collection records collection date/time and imports the RSKA Notes v17 setup PDF.
- If import is unavailable, users can create 1-10 MPs manually and complete the full collection record.
- Collection duration is calculated from setup date/time to collection date/time.
- Collection includes post-calibration, calibrator model/serial, optional calibration photo, weather, source observations, optional collection photos and notes.
- Photo pickers open only after Take picture or Upload from device is selected.
- Word heading On-site observations is RSKA green and regular weight.

## Deploy
Replace all files in the root of the GitHub repository, commit and push. GitHub Pages continues using the same URL.

## Important
The PDF import route is designed for setup PDFs generated by this v17 build. Older RSKA Notes PDFs do not contain the embedded structured payload and will use the manual fallback. Browser PDF creation/import requires the hosted HTTPS app and an internet connection for jsPDF/PDF.js.

## v17.1 observation dictation update
- Setup and Collection source-observation screens have a dedicated Dictate detailed observations control.
- Speech is transcribed directly into the observation text box and remains editable.
- Report Preview consolidates the recorded sources, notes and weather into a report-ready On-site observations paragraph.
- The consolidated paragraph can be reviewed, manually edited or supplemented with additional voice dictation before download/share.
- The reviewed paragraph is reused by Word, PDF and shared-PDF output.
- Speech recognition is browser-dependent; Chrome/Edge generally offer the strongest Web Speech API support. Manual typing always remains available.
